# 第3章 技术栈与依赖

## 3.1 技术栈概览

ScholarFlow 采用现代化的全栈技术方案，确保系统的性能、可维护性和可扩展性。

### 3.1.1 技术栈一览表

| 层级 | 技术 | 版本 | 用途 | 替代方案 |
|------|------|------|------|----------|
| **后端语言** | Python | 3.12+ | 服务开发 | Node.js, Go |
| **Web框架** | FastAPI | 0.100+ | API服务 | Django, Flask |
| **工作流引擎** | LangGraph | 1.0+ | 业务编排 | Airflow, Celery |
| **前端框架** | React | 18+ | 用户界面 | Vue.js, Angular |
| **前端语言** | TypeScript | 5.0+ | 类型安全 | JavaScript |
| **渲染引擎** | Marp CLI | 3.0+ | 生成PPT | PptxGenJS |
| **数据库** | SQLite | 3.45+ | 状态持久化 | PostgreSQL |
| **包管理** | uv | 0.1+ | Python依赖 | pip, poetry |
| **构建工具** | Next.js | 14+ | 前端构建 | Vite, CRA |

## 3.2 后端技术栈

### 3.2.1 核心语言：Python 3.12+

**选择理由**:
- ✅ 丰富的 AI/ML 生态库（LangChain, Transformers）
- ✅ 简洁优雅的语法，开发效率高
- ✅ 强大的异步支持（asyncio）
- ✅ 活跃的社区和持续的更新

**关键特性**:
```python
# 类型提示
from typing import TypedDict, List, Optional

class WorkflowState(TypedDict):
    task_id: str
    status: str
    chunks: List[str]

# 异步支持
async def process_pdf(pdf_path: str) -> str:
    result = await mineru_client.parse(pdf_path)
    return result

# 上下文管理器
async with get_checkpointer() as checkpointer:
    await checkpointer.save(state)
```

### 3.2.2 Web框架：FastAPI

**核心特性**:
- **自动文档**: Swagger UI + ReDoc 自动生成
- **类型验证**: Pydantic 模型自动验证
- **高性能**: 基于 Starlette，接近 Node.js 性能
- **异步支持**: 原生 async/await 支持

**代码示例**:
```python
from fastapi import FastAPI, UploadFile
from pydantic import BaseModel

app = FastAPI(title="ScholarFlow API")

class TaskCreateRequest(BaseModel):
    pdf_path: str
    presentation_style: str
    max_chars: int = 6000

@app.post("/api/tasks")
async def create_task(request: TaskCreateRequest):
    task_id = await workflow_service.start(request)
    return {"task_id": task_id, "status": "pending"}

@app.get("/api/tasks/{task_id}")
async def get_task_status(task_id: str):
    state = await workflow_service.get_status(task_id)
    return state
```

### 3.2.3 工作流引擎：LangGraph

**核心能力**:
- **状态管理**: 清晰的状态模型定义
- **节点编排**: 简单的节点添加和连接
- **条件路由**: 动态分支决策
- **中断恢复**: 支持暂停和恢复
- **检查点**: 自动状态持久化

**工作流定义**:
```python
from langgraph.graph import StateGraph

workflow = StateGraph(WorkflowState)

# 添加节点
workflow.add_node("initialize", node_initialize)
workflow.add_node("parse_pdf", node_parse_pdf)
workflow.add_node("stage1_process", node_stage1)

# 添加边
workflow.add_edge("initialize", "parse_pdf")
workflow.add_conditional_edges(
    "stage1_process",
    route_after_stage1,
    {"continue": "stage1_process", "merge": "merge_outlines"}
)

# 编译
compiled = workflow.compile(checkpointer=checkpointer)
```

### 3.2.4 数据库：SQLite

**选择理由**:
- ✅ 零配置，嵌入式数据库
- ✅ ACID 事务支持
- ✅ 高性能（读密集型场景）
- ✅ 单文件部署，维护简单

**使用场景**:
- LangGraph Checkpoint 存储
- 工作流状态版本管理
- 任务执行历史

**代码示例**:
```python
import aiosqlite

async def save_checkpoint(task_id: str, state: dict):
    async with aiosqlite.connect("checkpoints.db") as db:
        await db.execute(
            "INSERT INTO checkpoints VALUES (?, ?, ?)",
            (task_id, json.dumps(state), datetime.now())
        )
        await db.commit()
```

## 3.3 前端技术栈

### 3.3.1 核心框架：React 18

**核心特性**:
- **函数组件**: 现代化的组件写法
- **Hooks**: useState, useEffect, useContext
- **并发特性**: useTransition, useDeferredValue
- **Suspense**: 异步数据加载

**代码示例**:
```typescript
import React, { useState, useEffect } from 'react';

const TaskMonitor: React.FC = () => {
  const [status, setStatus] = useState<TaskStatus | null>(null);
  const [progress, setProgress] = useState(0);

  useEffect(() => {
    const interval = setInterval(async () => {
      const data = await api.getTaskStatus(taskId);
      setStatus(data.status);
      setProgress(data.progress);
    }, 1000);

    return () => clearInterval(interval);
  }, [taskId]);

  return <ProgressBar progress={progress} status={status} />;
};
```

## 3.4 外部服务依赖

### 3.4.1 LLM 提供商

#### DeepSeek
- **API**: `https://api.deepseek.com`
- **模型**: `deepseek-chat`
- **优势**: 高性价比，中文支持好
- **适用**: 生产环境首选

#### Kimi (Moonshot)
- **API**: `https://api.moonshot.cn`
- **模型**: `moonshot-v1-8k`
- **优势**: 长文本处理能力强
- **适用**: 处理长论文

#### OpenAI
- **API**: `https://api.openai.com`
- **模型**: `gpt-4-turbo`
- **优势**: 生态成熟，稳定性高
- **适用**: 预算充足的项目

**统一接口**:
```python
class LLMProvider:
    def __init__(self, provider: str, api_key: str, base_url: str):
        self.client = ChatOpenAI(
            model=provider,
            openai_api_key=api_key,
            openai_api_base=base_url
        )

    async def generate(self, prompt: str) -> str:
        response = await self.client.ainvoke(prompt)
        return response.content
```

### 3.4.2 PDF 解析：MinerU

**服务地址**: `https://mineru.net/api/v4`

**核心能力**:
- 高精度文本提取
- 图片和表格识别
- 数学公式解析
- 多语言支持

**调用流程**:
```python
# 1. 上传文件
upload_url = await mineru_client.get_upload_url()

# 2. 上传PDF
await mineru_client.upload_file(upload_url, pdf_path)

# 3. 轮询结果
result = await mineru_client.wait_for_completion(job_id)

# 4. 下载结果
markdown, images = await mineru_client.download_result(result)
```

### 3.4.3 渲染引擎：Marp CLI

**NPM 包**: `@marp-team/marp-cli`

**支持格式**:
- PPTX (PowerPoint)
- PDF
- HTML

**使用方法**:
```python
import subprocess

def render_marp(markdown_path: str, output_path: str):
    subprocess.run([
        "marp",
        markdown_path,
        "--output", output_path,
        "--pptx"
    ])
```

**自定义主题**:
```bash
marp slides.md --output presentation.pptx --theme custom.css
```

## 3.5 依赖管理

**优势**:
- 比 pip 快 10-100 倍
- 统一的依赖解析
- 虚拟环境管理
- .lock 文件保证可重现性

**配置文件**: `pyproject.toml`
```toml

name = "scholarflow"

[tool.uv]
```
